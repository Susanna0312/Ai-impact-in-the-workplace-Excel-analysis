# AI Impact in the Workplace | Excel Data Analysis

## Project Overview
This project explores how artificial intelligence is influencing workplace productivity, adoption, employee trust, and barriers to AI usage.

The analysis uses a dataset of 25,000 survey respondents and an interactive Microsoft Excel dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Excel Dashboard
- Data Cleaning and Validation
- Data Visualization

## Key Areas of Analysis
- AI adoption across job roles and industries
- AI adoption by company size
- Average weekly time saved through AI
- Changes in employee productivity
- Employee trust in AI-generated outputs
- Barriers to AI adoption
- Workplace AI policies

## Project Files
The Excel workbook includes the survey dataset, data checks, analysis sheets, KPI summaries, and interactive dashboard.

## Skills Demonstrated
Data analysis, data validation, KPI reporting, dashboard development, data visualization, and business insights.

## How to Explore
Download the Excel workbook and open it in Microsoft Excel to explore the dashboard and its interactive features.
